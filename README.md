## Project Overview

A simple Personal Task Manager built using Laravel. The system allows users to create, view, edit, delete, and update the status of their personal tasks.

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status
  - Pending
  - Completed

## Technologies Used

- Laravel
- PHP
- Blade
- MySQL
- HTML
- CSS
- JavaScript

## Database

The `tasks` table contains:

- `id`
- `task_name`
- `description`
- `status`
- `due_date`
